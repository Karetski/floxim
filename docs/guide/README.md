# Arcflow guides

- [Writing flows](writing-flows.md): nodes, routing, expressions, agents, humans, budgets, workspaces.
- [Using the CLI](cli.md): running, inspecting, answering, resuming, editing, scripting, and the TUI.
- [Scheduling and unattended runs](scheduling.md): cron, systemd timers and CI recipes.
- [Security](security.md): permissions, injection-safe shell steps, secrets, at-least-once side effects.
- [Harnesses and adapters](adapters.md): Claude Code, Codex, command adapters, plugins and the conformance kit.

The guides explain how to use Arcflow. The [specification](../spec.md) is the authoritative definition of behaviour; where a guide and the spec disagree, the spec is right and the guide is a bug.
