# 0009. Project name deferred

- Status: Accepted
- Date: 2026-09-30
- Decided by: Alexey (accepted the research.md §6 proposals when closing Stage 1)
- Context: research.md §6 row 9

## Decision

"Loom" stays a working name. Choosing the final name is a separate task, because "Loom" collides with Atlassian's Loom product and many existing repositories; candidates need PyPI, domain and trademark checks.

## Consequences

The package, CLI command and module names must be easy to rename before the first release (M8).
